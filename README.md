# Maria Cleaning Service — Homepage

A modern, responsive one-page cleaning-service homepage built with:
- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Vanilla JavaScript
- Google Fonts
- Responsive animations and scroll-reveal effects

## Files
- `index.html` — homepage
- `css/style.css` — all custom styling
- `js/main.js` — animations, navigation and back-to-top behavior

## Notes
The photos currently use Unsplash image URLs so the page can look polished immediately. Replace the URLs in `index.html` with your own licensed/local images when deploying.

Update the placeholder phone number, email, city and social links before publishing.

Open `index.html` directly in a browser, or use VS Code Live Server.
